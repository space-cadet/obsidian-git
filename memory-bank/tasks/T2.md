## Acceptance Criteria

- [x] Settings is registered and can be opened from the sidebar.
- [x] Required values can be entered and auto-saved in source.
- [ ] Invalid required values produce clear feedback in source.
- [x] Reopen/save behavior in the published build is user-verified.
- [x] Plugin data can be exported and imported without including the remote token.

## KISS Boundary

Start with one configuration path. Keep data migration limited to the versioned
envelope and legacy flat format; do not add profiles or advanced credential
providers until the basic workflow requires them.
