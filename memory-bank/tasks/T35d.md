# T35d: Mobile and Remote Transport Reliability

*Created: 2026-08-11 02:03 IST*
*Last Updated: 2026-08-11 02:03 IST*

**Status**: ⏸️ **PLANNED**
**Priority**: HIGH
**Parent**: T35

## Scope

Unify Git and GitHub HTTP behavior and establish an evidence-based mobile
repository-size and pack-index support boundary.

## Acceptance Criteria

- [ ] Git smart HTTP and GitHub API calls use the supported native Obsidian
  transport consistently.
- [ ] Document that response chunking does not remove whole-response native
  buffering unless a genuinely streaming transport is available.
- [ ] Decide and document the mobile pack-index strategy or limitation.
- [ ] Test large clone, pull, push, remote history, and commit expansion flows
  on Android and iOS.
- [ ] Record supported repository-size limits and failure guidance.

- T29 mobile release acceptance.
- T34c Android/Desktop authentication acceptance.
