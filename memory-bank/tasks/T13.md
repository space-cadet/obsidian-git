## Description

Provider read capabilities (`git.status`, `git.changed_files`,
`git.log`, `git.commit_changes`) each rebuilt repository state on every
call. T13 adds a shared, cached repository snapshot so consecutive reads
reuse one workdir/branch/log snapshot instead of re-walking the repo.

## Acceptance Criteria

- [x] Read capabilities share one cached snapshot.
- [x] Snapshot is invalidated on mutations that change repo state
      (stage, commit, pull, push).
- [x] Cache behavior covered by the T39b smoke verification (cache
      invalidation explicitly checked).
