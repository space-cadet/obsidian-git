# T1 — Port GitManager to isomorphic-git

*Created: 2026-05-30 16:50:00 IST*
*Last Updated: 2026-05-30 17:45:00 IST*

## Description

Rewrite the core git operations from `simple-git` (Node.js CLI wrapper) to `isomorphic-git` (pure JavaScript implementation) to enable mobile support. The current implementation imports Node `fs`/`path` modules which fail on mobile (iOS/Android).

## Background

The obsidian-git plugin currently uses `simple-git` which wraps the system `git` CLI binary. This approach works on desktop but fails completely on mobile where:
1. No `git` binary exists
2. Node `fs`/`path` modules are unavailable
3. Shell execution is blocked

The solution is to port to `isomorphic-git` — a pure JavaScript implementation of Git that runs in any JS environment including mobile browsers/WebViews.

## Architecture Decisions

| Decision | Rationale |
|----------|-----------|
| Use isomorphic-git over simple-git | Mobile compatibility — no git binary needed |
| Keep existing UI/settings code | Only swap engine, minimize risk |
| Token-based auth on mobile | No SSH agent on mobile platforms |
| Implement VaultFsAdapter | Bridge Obsidian Vault API to isomorphic-git fs interface |
| Shallow clones (`depth: 1`) | Performance optimization for mobile |
| Fast-forward only pulls | Safe default, avoid merge conflicts |
| Obsidian `requestUrl` for HTTP | Handles CORS on mobile, works everywhere |

## Risk Assessment

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|-----------|
| isomorphic-git performance poor on large repos | Medium | Medium | Shallow clones, exclude large files |
| Vault API insufficient for binary git objects | Medium | High | Use adapter.readBinary/writeBinary |
| Mobile auth storage not available | Low | High | Fallback to Obsidian settings |
| CORS issues on mobile | Medium | Medium | Use requestUrl, document proxy option |
| Build size too large | Low | Medium | Code splitting, tree shaking |
| Conflict resolution UX poor | High | Medium | Document manual resolution, add conflict UI |
