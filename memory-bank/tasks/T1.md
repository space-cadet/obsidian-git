# T1 — Port GitManager to isomorphic-git

*Created: 2026-05-30 16:50:00 IST*
*Last Updated: 2026-05-30 16:50:00 IST*

## Description

Rewrite the core git operations from `simple-git` (Node.js CLI wrapper) to `isomorphic-git` (pure JavaScript implementation) to enable mobile support. The current implementation imports Node `fs`/`path` modules which fail on mobile (iOS/Android).

## Background

The obsidian-git plugin currently uses `simple-git` which wraps the system `git` CLI binary. This approach works on desktop but fails completely on mobile where:
1. No `git` binary exists
2. Node `fs`/`path` modules are unavailable
3. Shell execution is blocked

The solution is to port to `isomorphic-git` — a pure JavaScript implementation of Git that runs in any JS environment including mobile browsers/WebViews.
