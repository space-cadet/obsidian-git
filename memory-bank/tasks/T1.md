## Details
Replace proxy-server-based Git HTTP with native `requestUrl` API. Implement core Git operations: clone, pull, push, add, commit, status.

## Progress
1. ✅ Replaced winston logger with simple Logger (no Node deps)
2. ✅ Created GitHttpClient using `requestUrl` (bypasses CORS, works on mobile)
3. ✅ Implemented GitManager with all core operations
4. ✅ Fixed `requestUrl` to handle binary pack files via ArrayBuffer
5. ✅ Added `throw: false` to let isomorphic-git handle Git protocol errors

## Files
- `src/gitManager.ts` — GitManager class with clone, pull, push, add, commit, status, sync
- `src/logger.ts` — Simple Logger singleton (no external deps)
- `src/main.ts` — Plugin entry point

## Decisions
- **requestUrl over fetch**: `requestUrl` runs at native Capacitor bridge level, bypassing CORS entirely. Works on desktop + mobile without proxy.
- **ArrayBuffer for binary**: `requestUrl` returns `arrayBuffer` which can be converted to async iterable for isomorphic-git.
- **throw: false**: Let isomorphic-git parse Git error responses (401/403) rather than throwing exceptions.

## Notes
- `collectBody()` merges Uint8Array chunks into single ArrayBuffer for POST requests
- `toAsyncIterator()` wraps ArrayBuffer into async iterable for isomorphic-git consumption
- `getStatusMessage()` provides human-readable status codes for logging
