## Decisions
- **Static logger**: `log.info(component, message)` pattern for simplicity
- **Log levels**: DEBUG for development, INFO for production
- **Console output**: Uses `console.log/error` directly, no file logging needed

## Notes
### Logger API
```typescript
log.setLogLevel(LogLevel.DEBUG); // or INFO
log.debug('Component', 'Message');
log.info('Component', 'Message');
log.warn('Component', 'Message');
log.error('Component', 'Message', error?);
```

### Status bar integration
GitManager updates status bar via `updateStatus()` for every operation:
- "Pulling changes..." → "Pull completed"
- "Pushing changes..." → "Push completed"
- "Failed to initialize" on errors
