## Acceptance Criteria

- [x] Local commits are listed in a readable view.

- [x] Remote history has a clear source state when available.

## KISS Boundary

Keep history read-only. Pagination and lazy detail loading are implemented in
response to measured history cost; branch trees and broad history caches remain
out of scope.
