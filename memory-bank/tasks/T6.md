### Phase 2: Real .git Repo Access (2026-05-31 01:17-01:38)

**Problem**: Plugin couldn't detect existing .git repos because `LightningFS` creates a virtual filesystem that cannot see the actual `.git` directory. `vaultPath` was also incorrectly set to the vault's display name, causing isomorphic-git to look in a non-existent subdirectory.

**Solution**: Built `ObsidianFsAdapter` — custom filesystem adapter that delegates to `app.vault.adapter` for native filesystem access.

#### Files Created
- `src/adapters/ObsidianFsAdapter.ts` — Custom fs backend for isomorphic-git
  - Implements all required fs methods: `readFile`, `writeFile`, `readdir`, `stat`, `mkdir`, `rmdir`, `unlink`, `readlink`, `lstat`, `symlink`, `rename`, `join`, `normalize`
  - Maps Obsidian's `Stat` type (`folder`/`file`) to isomorphic-git's expected format (`dir`/`file`)
  - Handles path normalization and joining

#### Files Modified
- `src/main.ts`:
  - Replaced `import FS from '@isomorphic-git/lightning-fs'` with `import { ObsidianFsAdapter } from './adapters/ObsidianFsAdapter'`
  - Changed `this.fs` from `new FS('gitfs')` to `new ObsidianFsAdapter(this.app)`
  - Fixed `detectRealGitRepo()` — now tries 3 methods: `adapter.read('.git/HEAD')`, `adapter.stat('.git')`, `git.findRoot()`
  - Fixed `vaultPath` to empty string `''` (vault root) instead of vault display name
  - All commands (pull/push/status/sync) now use centralized `ensureGitManager()`
- `src/gitManager.ts` — Removed LightningFS import, receives fs from main
- `src/views/GitSidebarView.ts` — `refresh()` now calls `ensureGitManager()` if not initialized, shows "Local only" mode
- `package.json` — Removed `@isomorphic-git/lightning-fs` from dependencies, added `.gitignore` for `*.zip`
