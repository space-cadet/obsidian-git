## Details
Create a dedicated sidebar panel showing git status, commit history, and file changes. This gives users visual feedback on what's happening with their repo without running commands.

## Features Needed

### Git Status View
- **Changed files list** — shows modified/added/deleted files with icons (M/A/D)
- **Staged vs unstaged** — visually separate staged and unstaged changes
- **Stage/unstage buttons** — checkbox or button to stage individual files
- **Diff preview** — show diff for selected file (inline or modal)

### Commit History (Log)
- **Commit list** — hash (short), message, author, date, relative time ("2 hours ago")
- **Branch graph** — simple linear or branch visualization
- **Commit details** — click to show full commit info, changed files
- **Checkout/revert** — optional: checkout specific commit

### Branch & Remote Info
- **Current branch** — displayed prominently
- **Remote status** — ahead/behind indicator (e.g., "3 ahead, 2 behind")
- **Branch list** — switch branches

## Technical Approach

### Obsidian Sidebar View
```typescript
class GitSidebarView extends ItemView {
  static VIEW_TYPE = "git-sidebar";
  getViewType() { return GitSidebarView.VIEW_TYPE; }
  getDisplayText() { return "Git"; }
  getIcon() { return "git-branch"; } // or custom icon
}

// Register in main.ts
this.registerView(GitSidebarView.VIEW_TYPE, (leaf) => new GitSidebarView(leaf, this));
```

### UI Rendering Options
- **Option A: Vanilla DOM** — Create elements directly, lighter weight
- **Option B: React** — If already using React in project (obsidian-ai does)
- **Option C: Obsidian's built-in components** — `Setting`, `MarkdownRenderer`, etc.

Recommended: **Vanilla DOM with Obsidian classes** — fits Obsidian's native look without heavy dependencies.

### Data Sources
- `git.statusMatrix()` — get changed files with status codes
- `git.log()` — get commit history
- `git.currentBranch()` — get current branch
- `git.listBranches()` — get all branches
- `git.getRemoteInfo()` — get ahead/behind

### Status Matrix Codes
```
[filepath, headStatus, workdirStatus, stageStatus]
[0,0,0] — unmodified
[0,1,1] — modified, staged
[0,1,0] — modified, unstaged
[0,0,2] — deleted, staged
[1,1,0] — added, unstaged
```
