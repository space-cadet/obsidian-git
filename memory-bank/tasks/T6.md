## Goal
Create a dedicated sidebar panel showing git status, commit history, and file changes with interactive staging/unstaging.

## Implementation

### Files Created
- `src/views/GitSidebarView.ts` — ItemView with full sidebar implementation
- `styles.css` — Complete sidebar styling

### Files Modified
- `src/gitManager.ts` — Added sidebar-specific methods:
  - `getDetailedStatus()` — file-by-file status (modified/added/deleted/untracked/staged)
  - `stageFile(filepath)` — stage individual file
  - `unstageFile(filepath)` — reset file to HEAD via `git.resetIndex`
  - `getLog(maxCount)` — commit history with oid, message, author, date
  - `getCurrentBranch()` — current branch name
  - Exported `GitFileStatus`, `GitCommit` interfaces
- `src/main.ts` — Registered view, added command + ribbon icon, `activateGitSidebarView()` method

### UI Panels
1. **Header**: Branch name (colored dot), ahead/behind count, "Up to date" when clean
2. **Changes**: File list with status icons (M/A/D/?/S/C), hover-reveal stage/unstage buttons
3. **History**: Commit log with 7-char hash, truncated message, relative date
4. **Footer**: Stage All, Sync, Refresh action buttons

### Features
- Auto-refresh every 30s when sidebar is visible
- Per-file stage/unstage with hover-reveal buttons
- Relative date formatting (just now → Xm ago → Xh ago → Xd ago → date)
- Vanilla DOM (no React dependency)
