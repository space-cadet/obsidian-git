## Notes
### Root cause of mobile failure
The bundle contained `require("buffer")` from `safe-buffer` (transitive dep via winston → readable-stream). On mobile, `require()` doesn't exist for Node built-ins.

### Bundle verification checklist
```bash
grep -n 'require("buffer")' main.js  # Should be 0
grep -n 'process.cwd' main.js          # Should be 0
grep -n 'process.env' main.js          # Should be 0
```

### If isomorphic-git needs process stubs
Add to esbuild config:
```javascript
define: {
  'process.env.NODE_ENV': '"production"',
  'process.platform': '"browser"',
  'process.cwd': '() => "/"'
}
```
