## Notes
### Root cause of mobile failure
The bundle contained `require("buffer")` from `safe-buffer` (transitive dep via winston → readable-stream, and also via isomorphic-git → sha.js). On mobile, `require()` doesn't exist for Node built-ins.

### Bundle verification results (v6)
```bash
grep -c 'require("buffer")' main.js   # 0 ✅
grep -c 'require("path")' main.js      # 0 ✅
grep -c 'process.cwd' main.js          # 1 (guarded by typeof check) ✅
grep -c 'process.env' main.js          # 1 (guarded by typeof check) ✅
grep -c 'require("obsidian")' main.js  # 4 (external, correct) ✅
```

### esbuild config changes
```javascript
// Removed from builtins external:
external: [
  ...builtins.filter(b => b !== 'buffer' && b !== 'path')
]

// Banner stub:
if (typeof process === 'undefined') {
  globalThis.process = {
    cwd: function() { return '/'; },
    env: {},
    platform: 'browser',
    version: 'v16.0.0'
  };
}
if (typeof Buffer === 'undefined') {
  globalThis.Buffer = require('buffer').Buffer;
}
```
