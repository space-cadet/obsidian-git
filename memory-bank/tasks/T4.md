## Details
Implement automatic sync at configurable intervals with proper cleanup on plugin unload.

## Progress
1. ✅ Auto-sync interval setting (in minutes, 0 = disabled)
2. ✅ `setInterval` with `window.setInterval` for browser compatibility
3. ✅ Clear interval on plugin unload
4. ✅ Reconfigure interval when settings change
5. ✅ Default commit message template with `{{date}}` placeholder

## Files
- `src/main.ts` — `setupAutoSync()`, `clearAutoSync()`, `syncVault()`

## Decisions
- **Interval in minutes**: User-friendly, converted to ms internally
- **Reconfigure on settings change**: `saveSettings()` calls `setupAutoSync()`
- **Cleanup on unload**: `onunload()` clears interval to prevent leaks

## Notes
- `syncVault()` formats commit message by replacing `{{date}}` with `new Date().toLocaleString()`
- If no changes detected, shows "No changes to commit" notice instead of empty commit

## Issues
- ⚠️ Auto-sync runs even if plugin is inactive (tab not focused) — consider checking `document.visibilityState`
- ⚠️ No exponential backoff for failed syncs — will retry every interval regardless of failures

## Next Steps
