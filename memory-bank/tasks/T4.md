## Details

Build the Changes component for viewing file state and performing the basic local file actions.

## Subtasks

- [x] T4a: File list and target layout
- [x] T4b: Stage and unstage
- [x] T4c: Commit message
- [x] T4d: Commit action
- [x] T4e: Preserve panel rendering and scroll position
- [ ] T4f: Filtering, sorting, and revert actions
- [ ] T4g: Keyboard range and non-contiguous selection

## Acceptance Criteria

- [x] Changed files appear in a local Changes list.
- [x] A file can be staged and unstaged.
- [x] A message can be committed and the clean state is shown in an installed Obsidian host.

## Implementation Update

- The fixed Changes action bar now includes Pull and Push buttons alongside
  Select All, Stage, Unstage, and Refresh.
- Pull and Push use the same queued remote operation path as the Settings
  actions and record their request, progress, and result in Activity.

## KISS Boundary

Start with direct file actions. Add selection or bulk-action machinery only if
the basic workflow demonstrates a need.
