## Details
Build an Obsidian plugin for git synchronization using isomorphic-git (pure JS, no native git binary). Supports desktop (Electron) and mobile (iOS/Android). Features: three-tab sidebar (Changes, History, Git Log), auto-sync, file staging, push/pull with credentials.

## Decisions
- Used isomorphic-git instead of native git binary for cross-platform compatibility (mobile support)
- Custom ObsidianFsAdapter because isomorphic-git needs an fs object with readFile, writeFile, readdir, stat, mkdir, rmdir
- Node.js fs fallback via `window.require` for .git pack files (Obsidian's readBinary returns null for .idx files)
- Lazy git manager initialization — only creates GitManager when sidebar opens or sync command runs
- Settings tab opens via gear icon in sidebar header
- Refresh interval 0 = disabled (no auto-refresh)
- Local-only mode when no repo URL configured (skip push/pull)

## Errors & Lessons
- **Pack index null buffer**: Obsidian's `DataAdapter.readBinary()` returns null for `.git/objects/pack/*.idx` files. Fixed with Node.js `fs` fallback via `window.require` on desktop. Mobile still needs solution.
- **path resolution bug**: `findRoot` failed with empty `vaultPath` — changed default from `''` to `'.'`
- **Credential format**: Fine-grained PATs work with any username for basic auth. Settings UI updated to clarify.
- **UI state confusion**: Header showed "Git repo detected" even when no .git existed — fixed by checking `.git/HEAD` existence via `detectRealGitRepo()`
- **statusMatrix row format**: Returns `[filepath, HEAD, WORKDIR, STAGE]` — `row[0]` is the path string, not the array
- **CRITICAL: `findRoot` expects a FILE path, not directory**: `git.findRoot({ fs, filepath: '.' })` fails because `findRoot` walks up the tree from a file path, and `.` has no parent in its logic. This caused existing repos to NOT be detected. Fixed by using `filepath: 'dummy.txt'` (findRoot doesn't require the file to exist). Also added Node.js fs fallback for desktop detection.
- **Platform detection**: Desktop (Electron) has `window.require` and `window.process`. Mobile (WebView) does not. Detection must happen at plugin load. Desktop should use Node.js fs for repo detection (most reliable). Mobile must use Obsidian adapter + findRoot.
- **Diagnostic command**: Removed during LightningFS→ObsidianFsAdapter refactor (commit 5cc6b11). Restored as `Run compatibility diagnostics` — shows platform, fs capabilities, repo detection result, git init test.
- **statusBarItem can be null on mobile**: `addStatusBarItem()` may return null on mobile, causing `ensureGitManager()` to return null even when repo exists. Fixed by making statusBarItem optional.
- **Buffer undefined on mobile**: isomorphic-git uses Node.js `Buffer` which doesn't exist in mobile WebView. Added `buffer` npm package with mobile-only polyfill.
- **Obsidian list() returns vault-root-relative paths**: `DataAdapter.list('.obsidian')` returns `.obsidian/app.json` not `app.json`. isomorphic-git prepends the directory again, causing `.obsidian/.obsidian/app.json` ENOENT. Fixed by stripping directory prefix in `readdir()`.
- **Fresh repo 'no commits' error**: `git.log()` throws "Could not find refs/heads/main" on fresh repos. Should show friendly empty-state instead of error toast.
