## Details
Build an Obsidian plugin for git synchronization using isomorphic-git (pure JS, no native git binary). Supports desktop (Electron) and mobile (iOS/Android). Features: three-tab sidebar (Changes, Commits, Git Log), auto-sync, file staging, push/pull with credentials.

## Architecture Review Follow-up (2026-08-11)

The architecture review found release-relevant risks in credential handling,
operation coordination, clone/local-only initialization, mobile transport,
updater integrity, and CI coverage. These are recorded under T35 and its child
tasks rather than expanding T29 into a general issue backlog.

T29 remains the release and acceptance owner. The v1.0.0 gate must remain open
until T34 authentication acceptance, T29 mobile acceptance, and the applicable
T35 hardening tasks are complete.

The August 12 clone/progress audit added two release-relevant acceptance gates
under T35: interrupted clone recovery must have an explicit resumable or
restart-only contract, and progress telemetry must distinguish network bytes,
Git objects, and checked-out files. These are implementation-hardening items,
not a reopening of completed T33 UI work.

The August 12 implementation slice now preserves initialized `.git` state
across fresh/shallow clone interruption and provides the modal's separate
object, response-data, file, rate, ETA, and phase displays. Native
`requestUrl` buffering, shared operation coordination, protected replacement
backups, and real-device acceptance remain release gates. Local verification
now includes 28 Node tests and 10 isomorphic-git checks.

## Decisions Made
- **isomorphic-git over native git**: Cross-platform compatibility ✅
- **ObsidianFsAdapter over LightningFS**: Delegates to `app.vault.adapter` ✅
- **Node.js fs fallback**: `window.require('fs')` for pack index files on desktop ✅
- **Lazy git manager init**: Only created when sidebar opens or sync command runs ✅
- **Refresh interval 0 = disabled**: No auto-refresh when set to 0 ✅
- **Local-only mode**: Skip push/pull when no repo URL configured ✅
- **PAT auth**: Any username works with fine-grained PATs ✅
- **No conditional UI hiding**: All buttons always visible, disabled when not applicable ✅
- **Dev releases on every push**: `dev` tag auto-updated, pre-release, not latest ✅
- **Updater uses Obsidian APIs**: `requestUrl` and `vault.adapter` keep release checks and installation desktop/mobile compatible ✅
- **Dev updater identity**: Compare the embedded build commit hash with `main` HEAD for rolling `dev` releases ✅
- **Archive layout**: Copy unpacked plugin files to `dist/` directly and retain the versioned ZIP ✅
- **Hardening boundary**: T35 owns shared reliability, security, lifecycle, transport, updater, and CI improvements; T29 retains release packaging and acceptance ownership ✅
