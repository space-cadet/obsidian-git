# T35b: Operation Coordination and Lifecycle Safety

*Created: 2026-08-11 02:03 IST*
*Last Updated: 2026-08-11 02:03 IST*

**Status**: ⏸️ **PLANNED**
**Priority**: HIGH
**Parent**: T35

## Scope

Serialize repository mutations and make timers, views, progress UI, and plugin
unload safe in the presence of asynchronous operations.

## Acceptance Criteria

- [ ] Only one mutating Git operation can run at a time.
- [ ] Manual, sidebar, command-palette, and auto-sync paths share the same
  coordinator.
- [ ] Refreshes cannot overlap or update detached/stale view state.
- [ ] Plugin unload cancels or invalidates in-flight work and clears progress
  UI and timers.
- [ ] Progress UI reports success only on success and failure only on failure.
- [ ] Add concurrency and lifecycle regression tests.
