### Issue Found & Fixed: Buffer Not Bundled
- **Error on mobile**: `Buffer failed: failed to resolve module specifier "buffer"`
- **Root cause**: esbuild's `builtin-modules` package listed `buffer` as a Node.js built-in, so esbuild externalized it (didn't bundle). On mobile, there's no Node.js `buffer` module to `import()`.
- **Fix**: Filter `buffer` out of the `builtins` array in `esbuild.config.mjs`:
  ```javascript
  ...builtins.filter(b => b !== "buffer")
  ```
- **Result**: `buffer` is now bundled inline (203 references in output, zero runtime imports)

## Key Lessons
1. **esbuild external list is critical**: `builtin-modules` includes packages like `buffer` that are NOT actually available in browser/mobile contexts. Must audit the external list carefully.
2. **Dynamic `import()` of npm packages only works if bundled**: `import('buffer')` at runtime requires the module to be either (a) bundled, or (b) available in the environment. Mobile WebView has neither.
3. **Spike methodology works**: Found the buffer issue quickly through iterative testing rather than discovering it mid-implementation.
