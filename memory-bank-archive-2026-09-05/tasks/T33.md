## Scope

Implement a dark-themed Git progress modal with dynamic updates, fix mobile crash on large repo pulls via chunked ArrayBuffer streaming, and match desktop UI to mobile design per user-provided screenshots.

## Issues Addressed

### Issue #1: Mobile Crash During Pull
- **Symptom**: Obsidian crashes when pulling large repos (100MB+) on mobile. App shows download progress but then terminates after 15-20 seconds.
- **Root Cause**: `GitHttpClient.collectBody()` aggregates all HTTP chunks into a single `ArrayBuffer`. For large packfiles, this exceeds mobile RAM. Additionally, `git.fetch` with `requestUrl` doesn't emit `onProgress` because the entire response is loaded into memory before isomorphic-git can process objects incrementally.
- **Solution**: 
  - Chunk `ArrayBuffer` into 64KB pieces in `toAsyncIterator()` using `subarray()` (view, not copy)
  - Use `git.clone` first in `shallowFetchAndCheckout` (more memory-efficient than fetch)
  - Add download timer showing elapsed time every second
  - Better error messages for OOM and timeout

### Issue #4: Desktop UI Doesn't Match Mobile
- **Symptom**: Desktop Changes tab and Commits tab look different from mobile. Section headers, file rows, buttons, and toggle bars have inconsistent styling. Chevron in Changes tab is tiny and non-functional on desktop.
- **Solution**: 
  - Overhauled `styles.css` to match mobile design exactly (user provided screenshots)
  - Changes tab: pill buttons, always-visible action buttons, purple M status, larger padding
  - Commits tab: centered toggle bar, full-row clickable, expanded state styling, larger font
  - Toggle bar: pill-like buttons with larger padding and border-radius

## Implementation Details

### GitProgressModal (`src/ui/GitProgressModal.ts`)
- New component: 291 lines
- Dark theme with Git Bash aesthetic (dark background, green accent, monospace)
- Phase-by-phase tracking: "Counting objects", "Receiving objects", "Resolving deltas", "Writing objects"
- Progress bar + percentage + KB transferred + status icon (✓/✗/⟳)
- Auto-close on success, error display on failure
- Falls back to simple `Notice` if `app` context unavailable

### GitManager Changes (`src/gitManager.ts`)
- `toAsyncIterator()`: 64KB chunking via `subarray()` — prevents OOM
- `shallowFetchAndCheckout()`: Uses `git.clone` first, falls back to `git.fetch` + `onMessage`
- `createProgressNotice()`: Returns `[onProgress, onMessage, hideNotice]` tuple
- `pull()`, `push()`, `cloneRepository()`: Integrated with `GitProgressModal`
- `fetchCommitFilesFromGitHub()`: Static method for commit file expansion when local objects unavailable
- `getCommitFiles()`: Downgrades 'not found' to warnings (expected with shallow clones)

### GitSidebarView Changes (`src/views/GitSidebarView.ts`)
- Commit rows: click handler moved to full row (not just message)
- Toggle bar: centered, buttons `flex: none`, desktop breakpoint
- Detail/meta padding: 32px consistent alignment
- Expanded state: `background-secondary-alt` styling
- `renderCommitDetail()`: Tries GitHub API fallback when local `getCommitFiles()` fails

### Styles (`styles.css`)
- Major overhaul: 400+ lines changed across 5 commits
- Dark modal: CSS animations, monospace fonts, responsive sizing
- Changes tab: pill buttons (border-radius: 20px), purple filled commit button, red force push, always-visible actions
- Commits tab: centered toggle bar, larger fonts, expanded state background, origin badge styling
