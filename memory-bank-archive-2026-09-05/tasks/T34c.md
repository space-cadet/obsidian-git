# T34c: Android/Desktop Authentication Acceptance Tests

*Created: 2026-08-10 22:34:02 IST*
*Last Updated: 2026-08-10 22:34:02 IST*

**Status**: ⏸️ **PLANNED**
**Priority**: HIGH
**Parent**: T34

## Scope

Verify the supported remote-authentication paths on a real Android device and
desktop Obsidian installation without disclosing credentials.

## Acceptance Checklist

- [ ] Read-only connection test succeeds for a selected private repository.
- [ ] Invalid/revoked token produces an actionable, secret-safe result.
- [ ] Repository access denial is distinguished from token rejection.
- [ ] Clone, pull, and push use the validated credentials successfully.
- [ ] Device-flow sign-in, refresh/recovery, and sign-out are verified if T34b
  is implemented.
- [ ] No token appears in plugin notices, exported debug logs, source, Git
  history, screenshots, or Memory Bank records.

## Dependency

- T34a and any chosen implementation work in T34b.
