# T31: Branch Tree View — Multi-Branch Visualization

*Created: 2026-06-01*
*Last Updated: 2026-06-01*

**Status**: ⏳ **BACKLOG / PENDING**
**Priority**: LOW
**Parent**: T29 (obsidian-git Plugin)

## Scope

Visual branch management: display local and remote branches as a tree/graph, allow switching between branches, creating new branches, merging, and viewing branch relationships.

## Motivation

- Power-user feature for users who want to work with multiple branches in their vault
- Could be useful for: feature branches for large writing projects, version experiments, backup branches
- **However**: Most Obsidian users just want "sync my vault" — branch management is git internals they shouldn't need to see

## Decision: Backlogged

This feature is **intentionally deferred**. Reasons:
1. **Scope creep**: The plugin's core value proposition is "sync my vault without knowing git"
2. **UI complexity**: Branch trees add significant UI surface area to a sidebar that's already dense
3. **Mobile concerns**: Branch operations on mobile are even more niche — touch UI for tree graphs is hard
4. **Conflict risk**: Branch switching in an active Obsidian vault could cause file overwrite/loss if not handled carefully

## When to Revisit

Reconsider T31 if:
- User explicitly requests branch switching functionality multiple times
- A clear use case emerges (e.g., "I need a draft branch for my paper")
- The plugin matures and has bandwidth for power-user features
- isomorphic-git adds better branch merge support (currently limited)

## Technical Notes (if revisited)

- isomorphic-git supports: `listBranches`, `checkout`, `branch`, `deleteBranch`
- **No merge support** in isomorphic-git — this is a major blocker for useful branch workflows
- Would need: branch list UI, checkout confirmation (warn about uncommitted changes), new branch input, delete with confirmation
- Graph visualization: simple list view first, graph view later if needed

## Implementation Sketch (Future)

1. New "Branches" tab in sidebar (4th tab)
2. List local branches with current branch highlighted
3. List remote branches under "Remote" subheader
4. Context menu (or buttons) per branch: Checkout, Delete, Merge (if supported)
5. Checkout: warn if working tree dirty, offer to stash or abort
